# مصمم البطاقات الاحترافي — ArtMark Card Studio

أداة ويب لتصميم بطاقات الهوية/العضويات على قالبك، وربطه بملف Excel، ثم توليد البطاقات دفعة واحدة.

**يعمل بالكامل في المتصفح** — لا خادم، لا قاعدة بيانات، ولا إرسال لبياناتك لأي مكان. كل الحسابات تتم على جهازك.

## المقومات
| العنصر | التفاصيل |
|---|---|
| المحرك | Fabric.js 5.3.1 (كانفس تفاعلي) + SheetJS (Excel/CSV) + JSZip + FileSaver |
| التدفق | رفع صورة القالب ← إضافة عناصر (نص/صورة/أشكال) ← ربط كل عنصر بعمود ← توليد ZIP |
| الصور المتغيرة | ارفع مجلد صور، واسم الملف = قيمة الخلية (يتجاهل الامتداد وحالة الأحرف) |
| المعاينة الحية | تنقّل بين السجلات على الكانفس قبل التوليد |
| الماسكات | قص دائري / حواف دائرية + Clipping Mask بشكل مرسوم |
| الخطوط | 11 خط عربي/لاتيني + رفع خط مخصص من جهازك |
| الواجهة | عربية RTL، ثيم داكن بلمسة لونية قابلة للتبديل (٦ لوحات)، وتوافق كامل مع الجوال |

## بنية الملفات
```
index.html        الصفحة الكاملة (HTML + CSS + JS مضمّنة)
css/theme.css     الثيم: الرموز، المكوّنات، الجوال، لوحات Accent
assets/           شعار + أيقونة التبويب (PNG)
```

## النشر على GitHub Pages
1. أنشئ مستودعاً (أو استخدم `ID-CARDS`).
2. ارفع `index.html` إلى **ال جذر المستودع**، مع مجلدي `css/` و`assets/`.
3. Settings → Pages → **Source: Deploy from a branch** → `main` / `/ (root)` → Save.
4. انتظر دقيقة، والرابط: `https://<user>.github.io/<repo>/`

> المسارات نسبية (`css/theme.css`, `assets/…`) فيجب أن تبقى الملفات بنفس الترتيب.

## ملاحظات
- البيانات لا تغادر المتصفح: الملفات تُقرأ محلياً عبر FileReader.
- المستودع عام: لا تضع كلمات مرور أو ملفات فيها بيانات أشخاص.
- الدقة: تُصدَّر البطاقة بمقاس القالب المرفوع بالضبط — فارفع صورة عالية الدقة.
