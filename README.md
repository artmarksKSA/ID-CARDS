# بطاقات ArtMark — مولّد بطاقات العضوية

موقع ثابت بملف واحد: <https://artmarksksa.github.io/ID-CARDS/>

- **`index.html`** — كل شيء داخله (HTML + CSS + JS + الخط الرسمي مضمَّناً base64). لا بناء، لا حزمة، لا خادم.
- **٩ صور قوالب** بجانبه مباشرة (`.jpg`/`.png`) — الأسماء كما هي لأن الكود يقرأها بالاسم.

## ماذا يعمل
قالب من قائمة منسدلة (٩ عضويات «خاصة» + قوالب «عامة» ترفعينها وتُحفظ في متصفحك) ← ربط ملف Excel ← اختيار السجل من منسدلة الأسماء ← توليد صورة لكل عضو أو ZIP دفعة واحدة.

**الخصوصية أولاً**: ملفات Excel وصور الأعضاء تُقرأ في المتصفح فقط (FileReader) ولا تُرسل لأي مكان. المستودع **عام** — لا ترفعين بيانات أعضاء أبداً (`.gitignore` يمنع `*.xlsx/*.xls/*.csv/*.pdf` ومجلدات `photos/` و`members/`).

## الخط الرسمي
`Mohammad Bold Art` مُضمَّن داخل `index.html`، وهو خط: الواجهة، والنصوص الجديدة، وطبقات القالب (الاسم/رقم العضوية/تاريخ الانتهاء)، وأول خيار في قائمة الخطوط، ورسوم التصدير. لا يوجد مسار خارجي يمكن أن يُكسر. للاستبدال بخط آخر: عدّلي `tools/src/font.json` ثم أعيدِ البناء (بالأسفل).

## التشغيل محلياً
```bash
python3 -m http.server 8000     # ثم افتحي http://127.0.0.1:8000/index.html
```
فتحه بنقر مزدوج (`file://`) يعمل للقالب، لكن «إضافة قالب من جهازك» و`templates.json` تحتاجان خادماً محلياً.

## إعادة البناء بعد تعديل
```bash
python3 tools/src/patch_idcards.py index.html out/   # يولّد out/index.html من قالب الأصل + طبقة الأدوات
```
الفحوص (تحتاج `pip install playwright` وتشغيل خادماً محلياً): `python3 tools/src/test_e2e.py` و`test_pub.py` و`test_mobile.py` و`test_font.py`.

## للنشر
ادفعي `index.html` (ومجلد `docs/` للشرح) إلى فرع `main` — GitHub Pages من الجذر. **لا ترفعي `index.html` وحده ثم تمسحي الصور**: الصور التسعة مطلوبة بنفس المسارات.
